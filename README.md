# Python Projects

A collection of small Python learning projects, utilities, and command-line experiments. Each directory is an independent project rather than part of one application.

## Projects

| Project | Description |
| --- | --- |
| [Desktop Notifier](Desktop%20Notifier/) | Scheduled desktop-notification example |
| [Dice](Dice/) | Random dice roller |
| [HTML parser](HTML%20parser/) | HTML retrieval and parsing example |
| [Notification](Notification/) | Desktop-notification example |
| [QR](QR/) | QR code generation and decoding scripts |
| [Retrieving Text from URL](Retrieving%20Text%20from%20URL/) | Retrieve plain text from a URL |
| [Retrieving json](Retrieving%20json/) | Retrieve and parse JSON from a URL |

| [XML parser](XML%20parser/) | XML retrieval and parsing example |

## Running a Project

Use Python 3 and run scripts from their own directories. Several projects import third-party packages; install the packages referenced in the relevant source file before running that project.

The Flask application has its own setup instructions in [ToDo App/README.md](ToDo%20App/README.md).

## Notes

- These are learning exercises and may use platform-specific services or public web endpoints.
- The email example requests credentials interactively. Do not add credentials to source files.
- No repository-wide dependency installation is required.
